## Средний уровень сложности 



Добавлено 3 файла **.py** с решением заданий индивидуального варианта.



**squares.py** — задание 1, вычисление квадратов чисел (от 1 до 10) с помощью функции map. Для возведения каждого элемента в квадрат применяется лямбда-функция. Результат выводится в формате списка.



**sum.py** — задание 3, вычисление суммы чисел с помощью reduce из встроенного модуля functools. Функция последовательно применяет лямбда-выражение сложения ко всем элементам списка, сворачивая его в одно результирующее значение.



**fibonacci.py** — задание 5, генератор чисел Фибоначчи. Реализован через оператор yield в бесконечном цикле: каждое обращение к генератору возвращает следующее число последовательности без хранения всей последовательности в памяти.
