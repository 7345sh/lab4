## Средний уровень сложности 

Добавлено 3 файла **.py** с решением заданий индивидуального варианта.

**squares.py** — задание 1, вычисление квадратов чисел (от 1 до 10) с помощью функции map. Для возведения каждого элемента в квадрат применяется лямбда-функция. Результат выводится в формате списка.

**sum.py** — задание 3, вычисление суммы чисел с помощью reduce из встроенного модуля functools. Функция последовательно применяет лямбда-выражение сложения ко всем элементам списка, сворачивая его в одно результирующее значение.

**fibonacci.py** — задание 5, генератор чисел Фибоначчи. Реализован через оператор yield в бесконечном цикле: каждое обращение к генератору возвращает следующее число последовательности без хранения всей последовательности в памяти.

## Повышенный уровень сложности

Добавлено 2 файла .py с решением заданий повышенной сложности.

**compose.py** — задание 1, композиция функций. Реализована функция высшего порядка compose(f, g), которая принимает две функции и возвращает новую. Результат её вызова соответствует математической композиции f(g(x)): сначала применяется вторая функция, затем первая. В качестве аргументов переданы анонимные функции.

**filter.py** — задание 4, фильтрация данных из файла через генератор. Генератор filter_numbers открывает файл и читает его построчно, не загружая целиком в память. Каждая строка проверяется: пустые строки и строки, не являющиеся числами, пропускаются. Если число больше заданного порога — оно возвращается через yield. В папке также находится файл data.txt с тестовыми данными, которые используются при запуске.

Для работы кода не требуется установка дополнительных библиотек.
